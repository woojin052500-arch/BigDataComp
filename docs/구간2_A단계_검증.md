## 2. 표고 — 필터 창을 실측으로 정했다

COP30은 **DSM**이라 건물·수목 높이가 지표면 표고에 섞여 있다. 분위 필터로 걷어내되,
창을 키우면 건물은 더 잘 지워지지만 **실제 경사까지 깎인다.** 둘을 재봤다.

| 필터 | 급경사(>0.15) 보존율 | 건물 제거량 p90 | 판정 |
|---|---|---|---|
| 원본 (필터 없음) | 100% | 0 m | 건물 혼입 |
| **하위25% · 창3 (75 m)** | **93.8%** | **7.8 m** | **채택** |
| 하위25% · 창5 (125 m) | 87.7% | 12.6 m | 경사 12.3% 손실 |

산복도로 경사가 이 분석의 핵심이라 **보존율이 높은 창3**을 택했다.
창5는 건물을 4.8 m 더 지우는 대가로 급경사를 6.1%p 더 깎는다. 남는 장사가 아니다.

**필터가 의도대로 작동하는지 교차 확인** — 도로 노드 58,648개에서 원본−필터 차이를
구별로 봤다. 고밀·노후 원도심에서 보정량이 크고 평지·저밀에서 작아야 정상이다.

| 구 | 평균 보정 | | 구 | 평균 보정 |
|---|---|---|---|---|
| 서구 | **5.08 m** | | 동래구 | 1.94 m |
| 영도구 | 4.48 m | | 강서구 | **1.10 m** |
| 중구 | 4.36 m | | | |

예상한 방향이다. 필터가 건물을 잡고 있다.

### DEM 자체 검증

| 지점 | DEM 최고값(반경 1.5 km) | 실제 | 차이 |
|---|---|---|---|
| 금정산 고당봉 | 786.0 m | 801.5 m | −1.9% |
| 승학산 | 486.8 m | 497.0 m | −2.1% |

30 m 격자에서 뾰족한 봉우리가 평활화되는 정상적인 폭이다.
좌표 변환도 검산 통과 (부산시청 → x 206,886.3 / y 287,022.7).

> **내가 틀린 것**: 처음에 봉우리 위경도를 기억으로 적어 넣었는데 고당봉이 500 m,
> 황령산이 1.4 km 어긋나 있었다. DEM이 틀린 게 아니라 내 좌표가 틀린 거였다.
> **좌표는 기억으로 쓰지 않는다.** (정정이력에 추가)

### 경사 산출 방식

시·종점 표고차를 쓰지 않는다. 이유는 두 가지 —
(1) 짧은 구간에서 노이즈가 경사로 둔갑하고, (2) DSM이라 한쪽 끝이 건물 위일 수 있다.

→ **20 m 간격 샘플링 후 표고열의 최소제곱 회귀 기울기.** 구간 내 최대 경사도 함께 저장.
→ **20 m 미만 구간은 NaN.** 값을 만들어내지 않는다 (해당 길이대의 53.7%가 표고차 0).

표본 300구간 실행 결과:

| 지표 | 값 |
|---|---|
| 경사 산출 / 20 m 미만 결측 | 242개 / 58개 (19.3%) |
| 회귀 경사 중앙 / p90 | 0.0208 / 0.1143 |
| 구간 내 최대경사 중앙 / p90 | 0.0891 / 0.3538 |
| **비현실 경사(>0.5)** | **0개** |

원본 시·종점 방식에서는 1.2%가 비현실 경사로 나왔다. **이 방식에서는 0이다.**
84,000구간 전체 소요 추정 **약 7분**.

## 3. 강우 — IDW를 쓰지 않기로 했다

WBS 구간2 4단계는 "AWS 지점 기준으로 공간 보간 (최근접 또는 IDW)"이다.
**둘 다 검증에서 탈락했다.**

정상상태 기간 **2021~2025, 13지점**으로 잡았다 (904 사상 2020-10, 942 남구 2019-04 이설 이후).
결측은 `유효시간비율`로 보정했다 (재검토 D1).

**LOO 교차검증** — 각 지점을 나머지 12개로 예측. 기준선은 "전체 평균으로 예측".

| 방법 | 연강수 R² | 30mm↑ R² | 판정 |
|---|---|---|---|
| **평면 추세면 (1, x, y)** | **0.169** | **0.188** | **채택** |
| IDW p=1 | −0.128 | −0.228 | 기준선보다 나쁨 |
| IDW p=2 | −0.207 | −0.434 | 기준선보다 나쁨 |
| IDW p=3 | −0.358 | −0.670 | 기준선보다 나쁨 |
| 최근접 지점 | −0.780 | −1.326 | 가장 나쁨 |
| 평면 + 고도 | −4.024 | −6.919 | 13개 표본에 과적합 |

R²가 음수라는 건 **그냥 부산 평균값을 쓰는 것보다 못하다**는 뜻이다.
지점 13개 / 770 km²(지점당 59 km²)에서 거리 기반 보간은 성립하지 않는다.

평면 추세면만 양수다. 방향은 **동쪽으로 갈수록 강수 많음**(상관 0.516),
남북 방향은 거의 없음(0.020). 고도와는 오히려 음의 상관(−0.265) — 지형성 강수 신호가 없다.

```
연강수(mm)      = 1537.34 + 6.0824·동서km − 3.6896·남북km
30mm↑(회/년)    =    3.26 − 0.0524·동서km + 0.0023·남북km
기준점 (203781.71, 285025.98) EPSG:5187
```

**R² 0.17은 약하다.** 구간 3에서 `variable_influence()`로 rain을 뺐을 때 상위 구간이
얼마나 바뀌는지 확인하고 **가중치 0.20 유지 여부를 판단한다.**
어느 쪽으로 결론이 나든 이 수치를 보고서 3장 "결과의 한계"에 그대로 적는다.

## 4. 행정동 귀속과 관로 조인 — WBS 구간2 5단계 대체

원문 5단계 "하수관로를 구간에 공간조인, **버퍼 반경**을 정하고"는 맨홀 자료에
좌표 컬럼이 없어 **실행 불가능**하다. 소속 행정동의 속성을 조인한다 (결정팩 Q2, 승인 대기).

표본 300구간 실행: **행정동 귀속 실패 0건, 관로 결합 실패 0건.**
평균 매설연수 1.0~34.1년, 표본 안에서 서로 다른 값 82개.

전역으로 넓히면 **서로 다른 값은 206개가 상한**이다. 도로구간이든 격자든 마찬가지다.

## 5. `src/build_base.py` 사용법

```python
import build_base as bb

sg = bb.load_boundary()      # 행정동 206
E  = bb.load_edges()         # 클리핑된 무향 구간 83,839
S  = bb.load_steps()         # 계단 피처 598

el = bb.Elevation()                  # 창3·하위25% 기본
z        = el.at(x, y)               # 좌표 → 필터 표고
fit, mx  = el.slope(geom)            # 구간 → (회귀경사, 구간내 최대경사)

rn = bb.Rain()
r  = rn.at(x, y)                     # → 연강수_mm, 시간당30mm이상_회_년

dg = bb.dong_of(x, y)                # 좌표 → gu, dong, adm_cd
pa = bb.pipe_attrs()                 # 행정동 206개 관로 속성
```

**전부 좌표나 기하를 받는다.** 단위가 도로 구간으로 정해지든 100 m 격자로 정해지든
그대로 쓴다. B단계는 단위 객체를 만들어 이 함수들을 호출하고
`data/processed/segments_base.gpkg`로 저장하는 일만 남는다.

## 6. 남은 것 (B단계, Q1 답 이후)

1. 단위 객체 생성 — 도로 구간 병합 규칙 적용 / 또는 100 m 격자 생성
2. 각 단위에 경사·강우·관로 속성 결합
3. 계단 피처 598개를 단위에 스냅
4. `segments_base.gpkg` 저장
5. **완료 기준 — QGIS로 열어 부산 위에 얹히는지 눈으로 확인, 결측 비율 표 기록**

`Q1`이 정해지면 반나절이면 끝난다. 계산 소요는 84,000구간 기준 약 7분으로 문제없다.
