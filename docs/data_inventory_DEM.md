# 데이터 인벤토리 — DEM

확인 2026-09-03 · 출처 공공데이터포털 15059920 / 국토정보플랫폼 map.ngii.go.kr

작업분해 지정: 국토정보플랫폼에서 부산 도엽 신청. 승인에 며칠 걸릴 수 있어 먼저 신청.
백업 VWorld DEM 또는 SRTM 30m.

## 정정 — 신청·승인 절차가 아닐 수 있다

작업분해와 1차 지시서에 "도엽 신청 → 승인 대기 며칠"로 적었는데, 확인 결과
**로그인만으로 받는 '공개DEM' 경로가 따로 있다.**

공공데이터포털 `국토교통부 국토지리정보원_DEM_20240924`(15059920) 페이지의
기타 유의사항에 이용방법이 원문으로 적혀 있다.

> 이용방법 : 포털접속 → 간편지도 검색 선택 → 항목 선택(ex: 인덱스, 영역, 반경 ...)
> → 영역 지정 및 선택 → **공개DEM 선택** → 항목 선택
> (**다운로드를 위해서는 로그인이 필요합니다**)

공문·승인이 필요한 것은 5m급 고해상도 자료로 보인다. 공개DEM은 회원가입과 로그인만으로
받을 수 있을 가능성이 높다. **먼저 공개DEM을 시도하고, 해상도가 부족할 때만 승인 절차를 건다.**

## 리스크 — 대용량 파일전송 S/W

공공데이터포털 설명란 원문:

> 국토정보플랫폼 다운로드를 위해서는 **대용량 파일전송 S/W가 필요합니다.**
> 다운로드 시 자동으로 대용량 파일 전송 프로그램을 다운로드 받습니다.
> 대용량 파일전송 S/W는 국토정보플랫폼 공지사항 "대용량 파일전송 S/W 제공"을 통해 다운로드 가능합니다.

**브라우저 단순 다운로드가 아니라 전용 프로그램 설치가 필요하다.**

- 이 프로그램이 **macOS를 지원하는지 확인되지 않았다.** 웹 검색으로는 확정되지 않았고,
  국내 공공기관 전송 S/W는 Windows 전용인 경우가 흔하다.
- 지원하지 않으면 이 경로로는 DEM을 받을 수 없다. **로그인 후 실제 다운로드를 한 번
  시도해서 이 지점을 먼저 확인해야 한다.** 확인에 5분이면 된다.
- 자동 설치를 요구하는 프로그램이므로, 설치 여부는 본인이 판단해서 진행한다.

### 막혔을 때의 백업

| 대안 | 해상도 | 비고 |
|---|---|---|
| VWorld 공간정보 다운로드 | 10m / 30m 문의 사례 존재 | 별도 S/W 불필요할 가능성 |
| SRTM 30m | 30m | 즉시. 정밀도 낮음 |

**해상도가 경사 계산에 미치는 영향**

- 도로 구간의 평균 경사만 필요하므로 30m급으로도 산출은 된다.
- 다만 산복도로처럼 짧은 거리에 표고차가 큰 구간에서는 30m 격자가 경사를 평활화한다.
  급경사 구간이 실제보다 완만하게 잡히면 V항 도달시간이 과소평가되고,
  이 분석의 차별점이 약해진다.
- 어느 해상도를 썼는지 결과물에 반드시 명시한다.

## 절차

1. map.ngii.go.kr 회원가입 → 로그인
2. 간편지도 검색 → 인덱스 또는 영역으로 부산 지정
3. **공개DEM** 선택 → 다운로드 시도
4. 대용량 파일전송 S/W 설치 요구가 뜨면 macOS 지원 여부 확인.
   지원하면 설치 후 진행, 안 되면 VWorld로 전환
5. 저장: `data/raw/ngii_dem_busan_YYYYMMDD/` (도엽 여러 개면 폴더째)
6. 문서에 기록할 것: 격자 해상도, 도엽 수, 취득 경로(공개DEM인지 승인 자료인지)

# 실제 접속 확인 (2026-09-03, 로그인 후)

## 승인 대기 없음 — 확정

`간편지도 검색 → 행정구역 → 부산광역시 / 중구` 선택 시 결과가 바로 나온다.
공개DEM 7건이 즉시 목록에 뜨고 다운로드 버튼이 활성화된다.

- **2014 부산광역시** ← 부산 전역 단일 항목
- 2025 / 2024 / 2023 / 2022 / 2021 / 2014 **부산 35913** ← 중구 도엽, 연도별

공문 신청·승인 대기 절차는 없다. **DEM은 임계 경로에서 빠진다.**
다운로드 버튼을 누르면 신청서 폼이 뜨고, 작성 후 처리되는 구조다.

## 용량 제한

다운로드 팝업 안내 원문:

> 원활한 다운로드 서비스 운영을 위하여 항공사진을 제외한 다운로드는 **1회당 자료를 1GB로 제한**합니다.
> 자료별 평균 용량: 수치지도(10MB), 연속수치지도(무제한), 온맵(75MB), **DEM(75MB)**,
> 종이지도(10MB), 통계도(15MB)

DEM 1도엽 평균 75MB → 1회 약 13도엽. 부산 16개 구·군이면 여러 번 나눠 받아야 한다.
**2014 부산광역시 전역 단일 항목을 먼저 받는 것이 효율적**이다. 다만 2014년판이므로
강서구 에코델타시티 등 이후 대규모로 바뀐 지역은 현재 지형과 다르다. 결과물에 명시한다.

## 신청서 항목

이름(자동) / 생년월일(필수) / 사용목적(필수, 2단 드롭다운 — 행위허가·도시계획·**제작 및 활용**·행정 및 소송)
/ 상세용도(필수) / 사용자 준수사항 동의(필수)

## 반드시 지킬 것 — 국외 반출 금지

신청서 하단 경고 원문:

> ※ 공간정보관리법 제16조 및 제21조에 따라, **국토교통부 장관의 허가 없이 측량성과 국외 반출 시,
> 2년 이하의 징역 또는 2천만원 이하의 벌금**이 부과될 수 있음

**DEM 원본은 클라우드 분석 환경으로 올리지 않는다.**

- 클라우드 컨테이너가 국내에 있다고 보장할 수 없고, 업로드가 국외 반출로 해석될 여지가 있다.
- **DEM을 쓰는 모든 처리(경사 추출, 구간별 표고차 산출)는 본인 컴퓨터의 로컬 작업공간에서만** 수행한다.
- 클라우드로는 **구간별 경사값 테이블만** 넘긴다. 원본 래스터는 넘기지 않는다.
  파생 수치는 측량성과 원본이 아니다.
- 구글드라이브 팀 공유도 해외 리전 저장 가능성이 있으므로, 팀 공유는 경사값 테이블로 한다.

## 미해결 — 자동화로 누른 다운로드가 파일로 떨어지지 않음

신청서 제출 후 팝업은 닫혔고 오류도 없었으나 `~/Downloads`에 파일이 생기지 않았다.
`.crdownload` 임시 파일도 없다.

같은 증상이 공공데이터포털 하수맨홀 CSV(로그인 불필요, 15084501)에서도 재현됐다.
DEM 고유 문제가 아니라 **브라우저 자동화로 누른 다운로드가 파일 저장까지 이어지지 않는
문제**다. 추정 원인: 팝업 차단 / 크롬 다운로드 저장 위치 설정 / 전송 S/W 실행 대기.

**해결: 본인이 브라우저에서 직접 다운로드 버튼을 누른다.**
Downloads 폴더가 세션에 연결돼 있으므로 파일이 떨어지기만 하면 이후는 자동으로 이어진다.

사면을 찍었기 때문으로 판단된다. **정확한 정상 좌표를 확보한 뒤 재검증한다.**
현 시점에서 이 수치를 DEM 오차의 근거로 삼지 않는다.

## 경사 계산 — 작동 확인 및 주의점

Tobler 보정식이 정상 작동한다. 70대 기준(ALPHA 4.6 km/h) 100 m 통과시간:

| 경사 | 통과시간 | 평지 대비 |
|---|---|---|
| 0% | 1.55분 | 1.00배 |
| 15% | 2.63분 | 1.70배 |
| 30% | 4.44분 | **2.86배** |

경사 30% 구간은 평지의 2.9배가 걸린다. **경사 보정이 실제로 큰 차이를 만든다는
첫 수치적 근거다.**

### 주의 — 래스터 전체 경사도 통계는 쓰지 않는다

래스터 전체에 Horn 경사도를 돌리면 육지 픽셀의 63.1%가 경사 15% 이상,
중앙값 14.2°로 나온다. 이는 과대다. 원인 둘:

1. **해안선 아티팩트** — bbox의 절반이 바다라 해안선이 매우 길다.
   바다(0 m)와 육지 사이 단차가 급경사로 잡힌다.
2. **DSM 특성** — 건물·식생 가장자리가 급경사로 잡힌다.

**실제 파이프라인에서는 도로 구간 단위로 계산하므로 이 문제가 발생하지 않는다.**
구간의 시점·종점 표고 차를 구간 길이로 나누는 방식이며, 픽셀 단위 경사도를 쓰지 않는다.
기획서 v3의 원래 설계가 맞았음이 확인된 셈이다.

### DSM 한계와 완화

Copernicus GLO-30은 DSM이다. 건물·식생을 포함한 표면 모델이므로 도심에서
건물 높이가 경사에 섞일 수 있다. 완화 방법:

- 도로 구간 표고를 뽑을 때 **버퍼 내 최저값 또는 하위 25% 백분위**를 쓴다.
  도로면은 주변에서 가장 낮은 축이므로 건물 영향이 크게 줄어든다.
- 산복도로 일대는 저층 주거지가 많아 상대적으로 영향이 작다.
- **같은 포털의 SRTM GL1(30 m)로 동일 계산을 돌려 상위 30개 구간의 겹침을 측정한다.**
  이 한계가 결과를 흔드는지 정량화하는 근거가 되고, 서식 3장 "결과의 한계 및 보완점"에
  그대로 들어간다.
