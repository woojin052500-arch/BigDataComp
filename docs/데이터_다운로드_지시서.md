# 데이터 다운로드 지시서

작성 2026-09-03 · 담당 김지훈

분석 환경(클라우드·로컬 작업공간)의 외부 접속이 허용 목록으로 제한돼 있어
포털에서 자동 수집이 불가능하다. `pypi.org`와 `github.com`만 열려 있고
`data.go.kr`, `data.kma.go.kr`, `map.ngii.go.kr`, `jis.go.kr`, `overpass-api.de`,
`download.geofabrik.de`, `api.opentopography.org`는 모두 프록시에서 차단된다.

**받은 파일은 `busan-subsidence/data/raw/` 에 아래 파일명으로 넣는다.**
넣기만 하면 이후 파이프라인은 그대로 돈다.

---

## 우선순위 1 — JIS 지반침하 이력 (검증의 정답지)

이게 없으면 검증 자체가 성립하지 않는다. 가장 먼저 건다.

1. 공공데이터포털 로그인 → 국토교통부 지하안전정보 오픈API
   https://www.data.go.kr/data/15041891/openapi.do
2. **활용신청** → 일반 인증키 발급 (보통 즉시 ~ 1시간)
3. 활용가이드 PDF에서 오퍼레이션명과 요청 변수 확인
4. 시험 호출로 아래를 확인한다
   - 시도 파라미터로 부산 필터가 되는가
   - 위경도가 있는가, 없으면 주소만인가
   - 발생원인 분류가 들어 있는가
   - 발생일자·규모·복구여부가 있는가
   - 도로 함몰 사고와 GPR 공동 발견이 구분되는가
5. 전체 페이지 순회 수집

- 저장: `data/raw/jis_sinkhole_busan_YYYYMMDD.csv`
- 함께 남길 것: `docs/data_inventory.md`에 필드 설명 메모
- 막히면: 주소만 있으면 지오코딩 필요(카카오/네이버 지오코딩 API 또는 도로명주소 API)

지도 확인용: https://www.jis.go.kr/

## 우선순위 2 — DEM (승인 대기가 걸린다. 오늘 신청)

경사 보정이 이 분석의 유일하게 온전한 차별점이므로 DEM은 대체 불가다.

1. 국토정보플랫폼 https://map.ngii.go.kr 회원가입 → 로그인
2. 수치표고모델(DEM) 부산 도엽 신청. **승인에 며칠 걸릴 수 있으므로 오늘 건다.**
3. 승인 나면 다운로드

- 저장: `data/raw/ngii_dem_busan_YYYYMMDD.tif` (여러 도엽이면 폴더째)
- 백업(즉시 가능, 정밀도 낮음): VWorld https://www.vworld.kr DEM, 또는 SRTM 30m
  백업을 쓰면 해상도를 문서에 명시한다

---

## 우선순위 3 — 강우 (로그인만 하면 즉시)

1. 기상자료개방포털 https://data.kma.go.kr 회원가입 → 로그인
2. 데이터 → 기상관측 → 지상 → **방재기상관측(AWS)** → 시간자료
3. 지점: 부산 관내 전 지점 / 기간: 2018.01.01 ~ 2025.12.31
4. CSV 다운로드. 기간이 길어 나눠 받아야 할 수 있다
5. **지점 정보(위경도 포함) 파일도 같이 받는다** — 이게 없으면 공간 보간을 못 한다

- 저장: `data/raw/kma_aws_busan_2018_2025.csv`
- 저장: `data/raw/kma_aws_stations.csv`

---

## 우선순위 4 — OSM 도로망 (2026-09-04 확정: 본인 맥에서 직접 실행)

`overpass-api.de`, 미러 `overpass.kumi.systems`, `download.geofabrik.de`,
`openstreetmap.org` 가 **전부 차단**임을 실측으로 확인했다. 분석 환경에서 받는 경로는 없다.

**네트워크가 열린 본인 맥 터미널에서 `src/osm_extract.py` 를 직접 실행한다.**
절차는 `docs/OSM_추출_실행안내.md`. 지역 범위는 지오코딩이 아니라 아래 우선순위 5에서
확보한 행정동 경계 폴리곤으로 잡으므로 도로망과 행정경계가 어긋나지 않는다.

- 저장(스크립트가 자동): `data/raw/osm_busan_walk_YYYYMMDD.graphml`,
  `osm_busan_edges_YYYYMMDD.gpkg`, `osm_busan_steps_YYYYMMDD.gpkg`,
  `osm_busan_stats_YYYYMMDD.json`
- `stats.json` 이 구간 2 분석 단위 확정 회의에 가져갈 실측값이다
- 파일럿(`중구 동구 서구`)을 먼저 돌리고 전역을 건다

## 우선순위 5 — 행정경계 (2026-09-04 확보 완료)

`sgis.kostat.go.kr` 은 차단이지만 `github.com` 계열은 열려 있어 자동으로 받았다.

- 파일: `data/raw/sgis_admdong_busan_20260701.geojson` — 부산 206개 행정동, 16개 구·군
- 원자료 통계청 SGIS(공공누리 제1유형) · 취득 경로 GitHub `vuski/admdongkor` ver20260701(CC BY 4.0)
- 상세와 하수맨홀 정합성 검증 결과는 `docs/data_inventory_행정경계.md`

## 추가 후보 — 굴착·공사 이력

하수관로 노후도를 못 쓰게 되면서 P항에서 비중이 커질 변수다.

- `부산광역시_건설공사 현황` 오픈API https://www.data.go.kr/data/15034085/openapi.do
- 확인할 것: 공사 위치(좌표 또는 주소)가 있는가, 굴착 여부를 구분할 수 있는가, 기간이 있는가
