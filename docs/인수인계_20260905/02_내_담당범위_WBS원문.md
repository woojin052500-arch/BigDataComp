## 구간 3 (8쪽) — P항 · 미착수

> **변수 계산**
> | 변수 | 계산 방식 | 가중치 |
> |---|---|---|
> | 관로 노후도 | 버퍼 내 관로 평균 매설연수, 30년 이상 노후관 비율 | 0.45 |
> | 굴착·공사 이력 | 대심도·도시철도 공사 구간과의 거리, 굴착 이력 밀도 | 0.25 |
> | 누적 강우 | 구간별 연평균 강우, 시간당 30mm 이상 호우 발생 횟수 | 0.20 |
> | 관경·지질·매립 | 최대 관경, 매립지 여부. 근거가 약한 탐색 변수 | 0.10 |
>
> 가중치는 전국 지반침하 1,433건의 원인별 비율에서 가져왔다.
> **임의로 정한 값이 아니라는 점을 보고서에 반드시 적는다.**

> **정규화**
> ```python
> from scipy.stats import rankdata
> def pct(x):                       # 백분위 순위 0~1
>     return (rankdata(x) - 1) / (len(x) - 1)
> P = 0.45*pct(pipe_age) + 0.25*pct(excavation) + 0.20*pct(rain) + 0.10*pct(etc)
> P = pct(P)                        # 곱하기 전에 한 번 더
> ```
> 최소최대 정규화를 쓰지 않는다. 이상치 하나가 척도를 지배한다.

> **탐색 변수 영향 확인** 관경·지질을 넣었을 때와 뺐을 때 상위 100개 구간이 얼마나
> 겹치는지 센다. 차이가 없으면 최종본에서 뺀다. 이 결과는 보고서 한계 항목에 그대로 들어간다.

## 구간 4 (10쪽) — V항과 결합 · 미착수

> **경사 보정 도달시간**
> ```python
> ALPHA = 4.6      # km/h, 70대 평지 보행속도 기준 (Bohannon 1997)
> def speed(slope):                 # slope = rise/run
>     return ALPHA * np.exp(-3.5 * np.abs(slope + 0.05))
> ```
> 원식의 6km/h는 성인의 빠른 보행이다. 4.6으로 낮춰 쓰되,
> **결과를 절대 도달시간이 아니라 상대 도달시간으로 부른다.**

> **세 가지 거리** ① 직선거리(행정 기준선) ② 네트워크 거리(NetworkX 최단경로, 가중치=구간 길이)
> ③ 경사 보정(가중치를 통과시간으로) — 대상 시설은 병원·소방서·대피소·정류장

> **도로 차단 시뮬레이션** 범위: **P 상위 1,000개 구간만.** 전 구간에 돌리면 며칠이 날아간다.
> **이 제한은 보고서 분석방법에 명시한다.**
> 방법: 구간 하나를 그래프에서 제거 → 영향권 노드의 ③ 도달시간 재계산 → 증가분 저장 → 원복
> 주의: 전체 재계산이 아니라 영향권만. 시작 전 10개로 시간을 재보고 총 소요를 추정.
> 감당이 안 되면 상위 300개로 줄인다.
