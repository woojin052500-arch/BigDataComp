## 2. 강우 (기상청 AWS 시간자료)

**로그인 필요.**

1. https://data.kma.go.kr/ 로그인
2. 데이터 > 기상관측 > 지상 > **방재기상관측(AWS)**
3. 상단 탭에서 **파일셋** 선택 (URL의 `tabNo=1`만으로는 탭이 안 잡힌다. 탭을 클릭해야 한다)
4. 검색조건: 자료형태 `시간 자료` / 기간 `2018` ~ `2025` / 지점 트리에서 **부산광역시** 체크
5. `> 조 회` → **전체 108건**
6. 표 헤더의 전체선택 체크박스 클릭 → 우측 하단 빨간 **다운로드**
7. **사용분야 선택 팝업**이 뜬다 → `학술/연구` 선택 → **신청**
8. 페이지당 30건이므로 **1~4페이지를 각각 반복**

**함정 (전부 실제로 겪음)**
- **다운로드가 즉시 안 떨어진다.** 서버에서 zip을 만드는 데 **40초~1분** 걸린다.
  20초 기다리고 "실패했다"고 판단하면 안 된다. 파일명은 `YYYYMMDDHHMMSS.zip` 형식으로 떨어진다.
- 페이지당 건수를 50으로 바꿔도 **페이지네이션은 30건 기준으로 유지**된다.
- 페이지를 넘기면 **선택이 초기화**된다. 페이지마다 전체선택을 다시 눌러야 한다.
- `form_input`으로 체크박스를 조작하면 `checked`만 바뀌고 행에 전파되지 않는다.
  **실제 좌표 클릭**이어야 한다.
- 페이지 이동·재조회 후 DOM ref가 무효화된다. 매번 다시 찾아야 한다.
- zip 안에 zip이 들어 있다. **2단계 압축 해제** 필요.

```bash
# 2단계 해제
for f in 2026*.zip; do unzip -oq "$f" -d outer; done
for z in outer/*.zip; do unzip -oq "$z" -d inner; done
```

### 지점정보 (좌표·이설 이력)

1. 데이터 > **메타데이터 > 지점정보 > 관측지점정보** (`/tmeta/stn/selectStnList.do?pgmNo=123`)
2. 조회 결과는 화면에 10건만 나온다. **우측 상단 `CSV` 버튼**으로 전체를 받는다
3. 컬럼: `지점, 시작일, 종료일, 지점명, 지점주소, 관리관서, 위도, 경도, 노장해발고도(m), 기압계·기온계·풍속계·강우계 지상높이`

## 3. DEM (Copernicus GLO-30)

1. https://portal.opentopography.org/ → Global Data → **Copernicus GLO-30**
2. 범위 지정: 서 128.70 / 동 129.35 / 남 34.85 / 북 35.42
3. 출력 형식 GeoTIFF, 이메일 입력 후 제출
4. Job이 끝나면 `rasters_COP30.tar.gz` 다운로드 → 풀면 `output_hh.tif`

**함정**
- 이메일 입력란이 있다. **사용자 본인이 입력해야 한다.**
- **국토정보플랫폼(map.ngii.go.kr)은 쓰지 말 것.** 공개DEM 열람은 로그인만으로 되지만
  실제 다운로드에 전용 S/W 설치가 강제된다. 자동화로 뚫리지 않았다.
- 한국 국가 측량성과 DEM을 쓰게 되면 **국외 반출 제한**(공간정보관리법 16·21조)에 걸린다.
  클라우드에 올리지 말고 로컬에서만 처리해야 한다. **COP30은 이 제한이 없다.**

**픽셀 크기 계산** (위도에 따라 달라지므로 그때그때 다시 잴 것)
```python
import rasterio, math
with rasterio.open(p) as ds:
    lat = (ds.bounds.bottom + ds.bounds.top) / 2
    m_lat = 111132.92 - 559.82*math.cos(2*math.radians(lat)) + 1.175*math.cos(4*math.radians(lat))
    m_lon = 111412.84*math.cos(math.radians(lat)) - 93.5*math.cos(3*math.radians(lat))
    print(abs(ds.transform.a)*m_lon, abs(ds.transform.e)*m_lat)
# 부산: 25.32 m x 30.82 m
```

## 5. 행정경계 (SGIS)

- https://sgis.kostat.go.kr/ → 자료제공 → 행정구역경계

**동명 정규화** (맨홀 데이터와 결합할 때 필수)
```python
import re
def norm(s): return re.sub(r'제(\d)', r'\1', str(s))   # 가야제1동 -> 가야1동
sg['dong'] = sg['adm_nm'].str.split().str[-1].map(norm)
```
이 정규화로 결합률 98.7% → **99.98%**.

## 7. 재현 시 공통 주의

### 한글 경로의 유니코드 정규화 (macOS)

macOS는 파일명을 **NFD**로 저장한다. 스크립트에 한글 경로를 하드코딩하면
NFC로 입력되어 **경로를 못 찾거나 중복 폴더를 만든다.** 실제로 한 번 만들었다.

```bash
# 나쁨
P="$HOME/mnt/부산_공모전/busan-subsidence"

# 좋음 — 실제 존재하는 것을 찾아서 쓴다
P=$(ls -d "$HOME"/mnt/*/ | grep -v -i download | head -1)busan-subsidence
```

### 파일명 규칙

`{출처}_{내용}_{날짜}.{확장자}` — 예 `sgis_admdong_busan_20260701.geojson`
