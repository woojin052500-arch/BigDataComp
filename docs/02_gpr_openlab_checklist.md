# 부산시 GPR 페이지 · 데이터 오픈랩 체크리스트

담당: 염우진 / 구간 1 (8/31~9/2)
**끝난 상태**: GPR 자료 확보 여부 판정 / 오픈랩 방문 가능 여부와 팀 내 방문 가능자 확정

## 1. 부산시 GPR 페이지

- 주소: https://www.busan.go.kr/depart/GPR
- 접속 에러 보고가 있었다. 확인 순서:
  - [ ] PC 크롬에서 접속 시도 (모바일 아님)
  - [ ] 안 되면 부산시 홈페이지 통합검색에서 "GPR" / "지반탐사" 검색으로 우회
  - [ ] 그래도 안 되면 부산시 건설본부/도로계획과에 전화로 페이지 이관 여부 확인
- 페이지가 열리면:
  - [ ] GPR 탐사 **구간** 목록이 공개돼 있는가 → 있으면 내려받기 (`data/raw/busan_gpr_구간_YYYYMMDD.*`)
  - [ ] **공동(空洞) 발견 현황**이 공개돼 있는가 → 있으면 내려받기 (`data/raw/busan_gpr_공동발견_YYYYMMDD.*`)
  - [ ] 파일이 아니라 게시글/보도자료 형태면 → 표를 수기로 옮기고 출처 URL 메모
- [ ] **판정 기록**: GPR 자료 확보 (가능 / 부분 가능 / 불가) + 근거 한 줄 → 카톡 공유

## 2. 부산 빅데이터 혁신센터 (데이터 오픈랩)

- 주소: https://busanbigdata.kr/
- **전화로 물어볼 것** (붙임 4 가점 항목):
  - [ ] 오픈랩 방문(열람) 가능 여부 — 일반 참가팀도 가능한가
  - [ ] 예약 절차 — 어디서, 며칠 전에, 무엇이 필요한가
  - [ ] 열람 가능한 데이터 **목록** — 특히 지반침하/도로/상하수도/GPR 관련이 있는가
  - [ ] 열람 데이터의 반출 가능 여부 (현장 분석만인지, 결과물 반출 조건은)
- [ ] 방문 가능하면 → 팀 내 **방문 가능자**(요일·시간대) 확정 후 카톡 공유
