작성: 2026-09-05 / 담당: 김지훈(데이터 전처리·분석)

## 1. 출처와 취득 방법

- 기관: 기상청 기상자료개방포털 (data.kma.go.kr)
- 메뉴: 데이터 > 기상관측 > 지상 > 방재기상관측(AWS) > **파일셋**
- 검색조건: 자료형태 `시간 자료`, 기간 `2018~2025`, 지점 `부산광역시`
- 조회 결과 **108건** → 페이지당 30건 × 4페이지를 나눠 다운로드
- 사용분야 신고: `학술/연구` (포털이 다운로드 시 필수로 요구함)
- 원본 zip 4개 (내부에 지점-연도별 zip → CSV)
- 지점정보: 데이터 > 메타데이터 > 지점정보 > 관측지점정보 → CSV 직접 다운로드

## 4. 지점 이설 — 분석에 영향을 주는 건

포털이 직접 경고한다: "동일한 지점번호라도 기간별 위치가 다를 수 있으니,
해당 지점의 위경도 변경 이력 확인 바람."

분석기간(2018~2025) 안에서 실제로 **좌표가 바뀐** 건은 하나다.

- **904 사상, 2020-10-31**: 사상구 감전동(35.1370, 128.9675) → 사상구 삼락동(35.1694, 128.9751).
  **이동거리 3.67km. 행정동이 바뀐다.**
  → 사상구 내부에서 지점을 행정동에 붙이면 2020년 전후로 다른 동에 귀속된다.
  → 대응: 사상구는 8년 전체를 하나의 지점으로 다루되 **구 단위로만** 사용하고,
    행정동 단위 귀속은 하지 않는다. 또는 2018~2020.10과 2020.11~2025를 분리한다.

- 937 해운대, 2024-11-30: 197m 이동 (노장고도 63.72m → 81.87m). 무시 가능.
- 나머지 이력 변경일은 좌표 동일 — 장비 교체·주소 재분류이며 위치 이동이 아니다.
- 910 영도의 683m 이동은 2010년으로 분석기간 밖이다.

## 5. 분석에 쓸 때의 제약 (반드시 보고서에 명시)

1. **공간 해상도**: 부산 면적 약 770km²에 유효 지점 13개 → 지점당 약 59km².
   100m 격자나 도로구간 단위로 내려가면 강우는 사실상 구 단위 이상에서만 변별력이 있다.
   P항의 rain 가중치 0.20은 **구·군 간 차이**를 반영하는 것이지 구간 간 차이를 반영하지 못한다.
   → 민감도 분석에서 rain을 뺐을 때 상위 구간이 얼마나 바뀌는지 반드시 확인할 것.
2. 지점값을 격자로 펼칠 때 IDW 등 보간을 쓰면 **관측하지 않은 값을 만들어내는 것**이므로,
   보간값임을 표기하고 보간 방식과 파라미터를 기록한다.
3. 968·969는 2021년 이후 없으므로 8년 평균 계산에서 제외하거나 기간 가중을 명시한다.
