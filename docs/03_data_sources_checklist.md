# 데이터 소스 체크리스트 — 하수관로 · 강우 · DEM

담당: 지훈 / 구간 1 (8/31~9/2)
파일명 규칙: `{출처}_{내용}_{날짜}.{확장자}` → `data/raw/` 에 저장. 원본은 절대 수정하지 않는다.

## 1. 하수관로

지반침하의 주요 원인(노후 하수관 누수) 분석용.

- [ ] 공공데이터포털에서 "부산 하수관로" / "부산광역시 하수관거" 검색
  - 후보: 부산광역시_하수관로 현황 (SHP 또는 CSV, 관경·매설년도·재질 포함 여부 확인)
- [ ] 국가공간정보포털(nsdi.go.kr) "하수도" 레이어도 교차 확인
- 확인할 것: **매설년도**(노후도 계산의 핵심)가 들어 있는가 / 좌표계가 무엇인가(5186? 5187? 파일 메타 확인)
- 저장 예: `data/raw/busan_하수관로_20260902.shp`

## 2. 강우

집중호우와 침하 발생의 시차 분석용.

- [ ] 기상청 기상자료개방포털 (data.kma.go.kr) → ASOS(종관) 시간자료
  - 부산 지점: **159 (부산)**. 필요하면 AWS 지점도 추가 (기장, 해운대 등)
  - 기간: 침하 이력 데이터가 커버하는 기간 전체 (예: 2018-01-01 ~ 최신)
- [ ] API로 받을 거면 공공데이터포털 "기상청_지상(종관, ASOS) 시간자료 조회서비스" 활용신청
- 확인할 것: 시간강수량 컬럼 / 결측 표기 방식(-9 등)
- 저장 예: `data/raw/kma_asos159_시간강수_20260902.csv`

## 3. DEM (수치표고모형)

지형(저지대·경사) 요인 분석용.

- [ ] 국토지리정보원 국토정보플랫폼 (map.ngii.go.kr) → 수치표고모형 90m/5m
  - 5m DEM은 로그인+활용신청 필요할 수 있음. 90m로 먼저 시작해도 됨
- [ ] 대안: 공공데이터포털 "국토지리정보원_수치표고모형" 검색
- 확인할 것: 좌표계(보통 EPSG:5186/5187/5179 중 하나 — QGIS로 눈 확인) / 부산 전역 커버 여부
- 저장 예: `data/raw/ngii_dem90_busan_20260902.tif`
- 읽기 테스트: `notebooks/00_env_setup.ipynb` 6번 셀(rasterio) 통과 확인 후 `rioxarray.open_rasterio()` 로
